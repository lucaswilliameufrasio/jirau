# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

Template version **0.4.0**.

### Features
- Rust core really linked on both platforms via UniFFI library mode: `scripts/build-ios-ffi.sh` (XCFramework + Swift bindings, Xcode project from XcodeGen `ios/project.yml`) and `scripts/build-android-ffi.sh` (cargo-ndk → `jniLibs/` + Kotlin bindings). Gradle runs the Android script automatically in `preBuild` (ABIs via `-Pjirau.rustAbis=x86_64`). The same scripts are used by jirau, `make`, CI, Android Studio and Xcode.
- `jirau run`: builds, installs and launches the app on a device/simulator, with automatic device selection, watch mode by default (`--no-watch`) and `-d <id>`.
- `jirau test`: unified runner for `core`, `ffi`, `android` (instrumented tests on the connected device), `ios` (XCTest on the simulator), `desktop` and `all`.
- `jirau upgrade`: real 3-way merge using `.jirau/template-base/` as the base; projects without a base get `<file>.jirau-new` side files for review. Supports `--force` and `--dry-run`.
- New `vault` template (password manager): SQLite storage with secrets encrypted with AES-256-GCM-SIV via `aws-lc-rs`; 32-byte key generated by the Rust core and stored in the iOS Keychain or wrapped by the Android Keystore; legacy plaintext databases are migrated automatically; titles, usernames and tags remain searchable plaintext metadata. The `starter` template (counter + greeting from Rust) remains the default.
- Bilingual CLI: global `--lang en|pt-BR`, `JIRAU_LANG` environment variable, defaulting to the system locale.
- Pinned technology versions centralized in `src/templates/versions.rs`, checked against the official registries by `scripts/check-template-versions.sh` (fails CI when outdated): Rust 1.99.1 (edition 2024), JDK 25 (LTS), Gradle 9.9.0 (bundled wrapper with distribution SHA-256), AGP 9.5.1, Kotlin 2.4.21, compileSdk/targetSdk 37, minSdk 26, Compose BOM 2026.09.00, NDK 30.0.16248370, UniFFI 0.32, rusqlite 0.41, aws-lc-rs 1.19, Swift 6 language mode, iOS 17+ deployment target, Xcode 27.
- English versions of the generated `TESTING_STANDARD.md` and `docs/setup-android.md` templates.

### Changes
- iOS simulator builds use ad-hoc signing (`CODE_SIGN_IDENTITY[sdk=iphonesimulator*] = "-"`), because the Keychain requires entitlements.
- Examples in `examples/` (secure-vault, mobile-gradle-starter, all-platforms-showcase, desktop-first-sqlite) are regenerated from the templates; `scripts/sync-vault-template.py` syncs the `vault` template from `examples/secure-vault`.

### Removed
- JetBrains Amper support: its Gradle plugin mode was discontinued and standalone Amper has no stable 1.0. `--amper` now fails with an explanation; Gradle is the only Android build system.

### Validation
- iOS simulator (iPhone 18 Pro, Xcode 27.2) and Android emulator (API 36, x86_64): `run`, tests, persistence and encryption.

### Documentation
- Documentation is now bilingual: English (default) and Brazilian Portuguese (`*.pt-BR.md`), updated to reflect the current state.

## [0.3.0] - 2026-11-09

### Features
- **Smart Device Selection in `jirau run [platform]`**: Automatically runs on a single connected Android device or booted iOS simulator; opens interactive picker when multiple are present; displays helpful setup guidance when none is available.
- **Unified Test Runner `jirau test [target]`**: Orchestrates test execution across Rust Core, FFI lifecycle integration tests, Android JUnit 5 unit tests, iOS XCTest, and Desktop Rune compilation.
- **Production-Ready "Secure Vault" Sample App**: Full-featured password manager showcasing SQLite with relational schema & indexes, search & categorization, cryptographic password generator with strength evaluation, Rune GPU Desktop UI, Jetpack Compose Material 3, and SwiftUI with `@Observable`.
- **Environment & Automation Improvements**: Headless Android SDK setup documentation & automated setup script, `.mise.toml` pinned versions, root Makefile automation, and enhanced `jirau doctor` fallbacks.
- **Material 3 Extended Themes & Plugins**: Design token generators for Compose and SwiftUI, plus `logger` plugin integration.
- **CI/CD Template Generation**: `--ci` flag adds ready-to-run GitHub Actions workflow (`.github/workflows/ci.yml`).

## [0.2.0] - 2026-11-08

### Features
- **Desktop Support (Rune UI)**: Native desktop applications rendered on GPU via `anomalyco/rune`, consuming the Rust core directly without FFI overhead.
- **SQLite Persistence (`--sqlite`)**: Embedded relational database in core via `rusqlite` with typed queries and native bindings.
- **JetBrains Amper Support (`--amper`)**: Declarative YAML configuration for Android projects.
- **Template Upgrade Engine (`jirau upgrade`)**: 3-way merge algorithm to synchronize projects with new template versions while preserving developer customizations.
- **Reference Showcase Projects**: Added `all-platforms-showcase`, `mobile-gradle-starter`, and `desktop-first-sqlite` in `examples/`.
